## 🚀 flye.win

**One key. Every API.** flye.win is an API marketplace: you create one key and use it across every API in the catalog, with clear limits, predictable pricing, and docs generated straight from the code.

| API | What it does |
| --- | --- |
| [**Stickers**](https://flye.win/apis/stickers) | Search stickers and animated GIFs, with ready-to-use links |
| [**CDN**](https://flye.win/apis/cdn) | Image hosting with public links, organized in projects and folders |
| [**Utils**](https://flye.win/apis/utils) | UUIDs, hashes, Base64, IP lookup — the small things every app needs |

```bash
curl https://flye.win/v1/utils/uuid -H "Authorization: Bearer $FLYE_KEY"
```

**Why developers pick it**

- 🔑 **One key for everything** — subscribe only to the APIs you use, authenticate them all the same way
- 🆓 **Free plan on every API** — no credit card to start
- 🧪 **Test keys** (`flye_test_…`) — integrate and run CI against documented examples without spending quota
- 📦 **Official SDKs** for JavaScript/TypeScript and Python, plus a public **OpenAPI 3.1** spec
- ▶️ **Try it in the browser** — every endpoint has a playground and examples in curl, JS, Python, Go and PHP
- 📊 **Full visibility** — per-request logs, usage and limits in real time on the dashboard
- 💳 **Pay your way** — card in BRL or USD, Pix and Pix Automático
- 🔒 **Security first** — two-factor authentication, scoped keys, IP allowlists and per-end-user rate limits

## 🧭 How I build

I lead flye.win end to end — product, architecture, infrastructure and the developer experience. A few principles I hold the team and the code to:

- **Developer experience is the product.** If the docs need a support ticket to be understood, the docs are wrong.
- **Fast by default.** Every page and every request has a budget, and we measure it.
- **No surprises on the bill.** Limits and prices are public, and quotas are visible before they run out.
- **Secure without friction.** Strong defaults that don't get in the way of shipping.
